# Прототипы пасхалок в накоплениях

- [Лендинг со входом в игру](https://ohnoazamat92.github.io/savings-snowman-prototype/)
- [Внутри Сферы — снежный survival](https://ohnoazamat92.github.io/savings-snowman-prototype/sphere-game.html)
- [Ёлка желаний](https://ohnoazamat92.github.io/savings-snowman-prototype/wish-tree.html)

Пиксельный снеговичок справа внизу лендинга открывает игру в той же вкладке. Нажмите на него или выберите ссылку клавиатурой и нажмите Enter. Вернуться можно кнопкой браузера.

Сфера: трёхминутный забег, автоатака, шесть улучшений и личный недельный рекорд. Соперники в рейтинге вымышлены, рекорд хранится в браузере. Есть оригинальная сгенерированная боевая музыка и короткие игровые эффекты. Музыка продолжается при выборе способности; на обычной паузе и при уходе из вкладки останавливается. Раздельная громкость и отключение — в «Управлении» и паузе, выбор сохраняется. [Источники ресурсов](public/assets/sphere-game/SOURCES.md).

Ёлка: 10 240 демонстрационных желаний, приближение к веткам, создание игрушки и ссылка на неё. Общего сервера хранения нет.

Прототип для обсуждения. Банковские операции и отправка форм отключены. В шапке остались «Накопления», «Вклад» и «Накопительный счёт». Только два продуктовых адреса ведут на оригинальный сайт Т-Банка; локальных копий этих страниц нет. Остальные банковские меню, ссылки и футер-каталог удалены из исходной разметки. Игра и ёлка сохранены. Макет воспроизводит десктопную страницу tbank.ru/savings/; мобильная адаптация самого лендинга не выполнена.

Исходники прежнего плюшевого персонажа с эмоциями и переносом сохранены в `src/Snowman.jsx` и связанных `pet-*` модулях, но на текущем лендинге этот компонент не подключён.

## Разработка

```sh
npm ci
npm run dev -- --host 127.0.0.1
npm run build && node --test tests/*.test.mjs
```

GitHub Pages публикует папку `docs` ветки `main`. Для обновления скопируйте содержимое `dist/client/` в `docs/`, сохраните `.nojekyll` и отправьте коммит.

Оригинальные материалы Т-Банка используются как референс прототипа; права на них принадлежат правообладателям.
