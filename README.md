# Лендинг накоплений со снеговичком

[Открыть прототип](https://ohnoazamat92.github.io/savings-snowman-prototype/)

Демонстрационный лендинг: снеговичок закреплён справа внизу. По наведению он моргает, по нажатиям показывает эмоции. После приветствия, моргания, прыжка, шарфа и танца отдельное нажатие запускает шейдерный снегопад на весь экран.

Прототип для обсуждения. Банковские операции и отправка форм отключены. Ссылки на продукты ведут на оригинальный сайт Т-Банка. Макет воспроизводит десктопную страницу tbank.ru/savings/; мобильная адаптация лендинга не выполнена.

## Разработка

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

Проверка: `node --test tests/snowfall.test.mjs`. Сборка: `npm run build`.

GitHub Pages публикует папку `docs` ветки `main`. Для обновления сайта скопируйте содержимое `dist/client/` в `docs/`, сохраните `.nojekyll` и отправьте коммит.

Оригинальные материалы Т-Банка используются как референс прототипа; права на них принадлежат правообладателям.

## Звуки

Мягкий тап и перелив колокольчиков при начале снега взяты из свободных библиотек Kenney и PWL (CC0). Источники и обработка: [SOURCES.md](public/assets/audio/SOURCES.md). Кнопка динамика отключает звук и сохраняет выбор. Наведение беззвучно. Проверка управления аудио: `node --test tests/pet-audio.test.mjs`.
