# Прототипы пасхалок в накоплениях

- [Снеговичок на лендинге](https://ohnoazamat92.github.io/savings-snowman-prototype/)
- [Ёлка желаний](https://ohnoazamat92.github.io/savings-snowman-prototype/wish-tree.html)
- [Внутри Сферы — снежный survival](https://ohnoazamat92.github.io/savings-snowman-prototype/sphere-game.html)

Сфера: трёхминутный забег, автоатака, шесть улучшений и личный недельный рекорд. Соперники в рейтинге вымышлены, рекорд хранится в браузере. Музыка в этой версии ещё не подключена.

Ёлка: 10 240 демонстрационных желаний, приближение к веткам, создание игрушки и ссылка на неё. Общего сервера хранения нет.

Демонстрационный лендинг: снеговичок появляется справа внизу. Зажмите и потяните его: упругий подвес, наклон, инерция и посадка перенесены из мобильного прототипа. Короткий тап сохраняет эмоции; перенос не переключает их. Стрелки перемещают персонажа, Escape отменяет захват. Новая позиция сохраняется до перезагрузки. По наведению он моргает, по нажатиям показывает эмоции. После приветствия, моргания, прыжка, шарфа и танца отдельное нажатие запускает шейдерный снегопад на весь экран.

Прототип для обсуждения. Банковские операции и отправка форм отключены. Ссылки на продукты ведут на оригинальный сайт Т-Банка. Макет воспроизводит десктопную страницу tbank.ru/savings/; мобильная адаптация лендинга не выполнена.

## Разработка

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

Сборка и проверки: `npm run build && node --test tests/*.test.mjs`. Сначала нужна сборка: тест упаковки проверяет её выходные файлы.

GitHub Pages публикует папку `docs` ветки `main`. Для обновления сайта скопируйте содержимое `dist/client/` в `docs/`, сохраните `.nojekyll` и отправьте коммит.

Оригинальные материалы Т-Банка используются как референс прототипа; права на них принадлежат правообладателям.

Тап — самый первый звук Kenney (bong_001) с исходной громкостью, захват — тот же звук с той же громкостью, отпускание — мягкий «пух». Звук отпускания срабатывает сразу и не дублируется при посадке. Источники тапа, захвата и отпускания Kenney и saangosu (CC0). Санными бубенцами при начале снега остаётся запись BrianJamesLong (CC0). Тап восстановлен из первой версии; другие звуки сохранены. Источники и обработка: [SOURCES.md](public/assets/audio/SOURCES.md). Кнопка динамика отключает звук и сохраняет выбор. Наведение беззвучно. Проверка управления аудио: `node --test tests/pet-audio.test.mjs`.

## Загрузка анимаций

Семь прозрачных WebP оптимизированы с 40,23 до 7,64 МБ при сохранении размеров, кадров, длительностей и альфа-канала. Сначала подготавливаются приветствие, моргание и удержание; во время эмоции — следующая по порядку, во время удержания — посадка. Предзагрузка и показ используют общий кэш запросов. Повторный тап во время эмоции по-прежнему не ставится в очередь.

Проверка: `node --test tests/pet-clips.test.mjs`. Для перекодирования исходных WebP: `python3 scripts/optimize-pet.py /path/to/original/pet public/assets/pet` (Pillow).
